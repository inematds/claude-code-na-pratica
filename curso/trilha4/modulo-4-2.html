🎯 Skills

Skills são pacotes de instrução que dão uma habilidade pronta ao Claude. Aqui estão 60+ em quatro coleções open-source. Cole a pasta da skill em ~/.claude/skills/ e o Claude passa a reconhecê-la. Cada link abre o SKILL.md correspondente.

SEO (25) Superpowers (14) Power Design UI/UX Pro Max

📥 Como instalar uma skill

Cada skill é uma pasta com um arquivo SKILL.md dentro. Para instalar, copie a pasta inteira para o seu diretório de skills:

cp -r biblioteca/skills/claude-seo/seo-technical ~/.claude/skills/

Depois, na próxima sessão, o Claude reconhece a skill automaticamente — e você pode invocá-la com /<nome-da-skill> ou simplesmente descrevendo a tarefa. Para avaliar antes de adotar, use o prompt P13 do Banco de Prompts.
