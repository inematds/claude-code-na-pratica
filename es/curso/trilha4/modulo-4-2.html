BIBLIOTECA · CATÁLOGO

🎯 Skills

Las skills son paquetes de instrucciones que le dan a Claude una habilidad lista para usar. Aquí están 60+ en cuatro colecciones open-source. Copia la carpeta de la skill en ~/.claude/skills/ y Claude empieza a reconocerla. Cada enlace abre el SKILL.md correspondiente.

SEO (25) Superpowers (14) Power Design UI/UX Pro Max

📥 Cómo instalar una skill

Cada skill es una carpeta con un archivo SKILL.md dentro. Para instalar, copia la carpeta completa en tu directorio de skills:

cp -r biblioteca/skills/claude-seo/seo-technical ~/.claude/skills/

Después, en la próxima sesión, Claude reconocerá la skill automáticamente — y podrás invocarla con /<nome-da-skill> o simplemente describiendo la tarea. Para evaluarlo antes de adoptarlo, usa el prompt P13 del Banco de Prompts.
