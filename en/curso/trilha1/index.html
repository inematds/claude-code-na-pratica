🧠 Memory System

Short-, medium-, and long-term memory—and CLAUDE.md as the project manual.

What it is:

Short (session), medium (project), and long (knowledge base).

Why learn:

Each level solves a different "forgetting" problem.

Key concepts:

Short · medium · long.

What it is:

What fits in the current session—and degrades when it fills up.

Why learn:

Knowing when to clean up maintains quality.

Key concepts:

Session · clear · start over.

What it is:

Separate projects into dedicated folders (5–8 buckets).

Why learn:

Organized context = more accurate answers.

Key concepts:

Folders · scope · 1 manual per folder.

What it is:

A file that explains the project to the AI (≈200 words).

Why learn:

It’s the average memory that isn’t lost between sessions.

Key concepts:

Project manual · short · 1 per folder.

What it is:

A knowledge base that accumulates what matters.

Why learn:

You stop repeating the same context every time.

Key concepts:

Knowledge base · subfolders · accumulation.

What it is:

A routine for saving conclusions in the right folder.

Why learn:

Turns conversation into reusable knowledge.

Key concepts:

Save · correct subfolder · reuse.
