🔐 Compliance

Security, API costs, and health checks to keep the system running.

P43Canonical

Offensive security red team (mega prompt)

When to use: audit the security of a codebase/project before production.

Você é um engenheiro sênior de segurança ofensiva contratado para fazer red-team neste codebase. Seu trabalho é invadir, exfiltrar dados e quebrar o negócio. Seja paranoico e minucioso — não assuma nada. Método: percorra o repositório inteiro de forma sistemática. Para cada arquivo que ler, pergunte: "Se eu fosse um atacante que já tem acesso de leitura, o que eu faria com isto?". Superfícies de ataque a cobrir: segredos e credenciais; segurança de banco (ex.: Supabase) e autorização; LLM / prompt injection; webhooks; dependências e cadeia de suprimentos; logging e exposição. Saída: achados ordenados por severidade, o caminho do exploit e a correção concreta de cada um. Não escreva um scanner — recomende poucos scanners open-source consagrados (ex.: Gitleaks, Semgrep, Trivy), diga quais três adicionar ao meu pre-commit, e assuma que isso barra ~80% dos problemas.

⌘ Slash commands & trivial commands

They aren’t prompts, but they’re part of the workflow.

  • /init (high effort) — getting Claude to understand the entire codebase.
  • /clear — reset the conversation (avoid "context rot").
  • /context — inspect context window usage.
  • /compact — compress the context while preserving what matters.
  • /model — switch between Opus / Sonnet / Haiku.
  • /cost — see the session’s token usage.
  • /agents — manage subagents.
  • /memory — open/edit the memory files (CLAUDE.md).
  • /<nome-da-skill> — invoke a skill.
  • /newbot (Telegram’s BotFather) — create a bot for your personal agent.
