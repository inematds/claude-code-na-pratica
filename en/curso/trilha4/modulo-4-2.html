🎯 Skills

Skills are instruction packages that give Claude a ready-made ability. Here are 60+ in four open-source collections. Copy the skill folder into ~/.claude/skills/ and Claude starts recognizing it. Each link opens the SKILL.md corresponding.

SEO (25) Superpowers (14) Power Design UI/UX Pro Max

📥 How to install a skill

Each skill is a folder with a file SKILL.md inside. To install, copy the entire folder to your skills directory:

cp -r biblioteca/skills/claude-seo/seo-technical ~/.claude/skills/

Then, in your next session, Claude recognizes the skill automatically — and you can invoke it with /<nome-da-skill> or simply describing the task. To evaluate it before adopting it, use the prompt P13 from the Prompt Bank.
