🤖 Agents

18 specialist SEO agents (open-source, MIT). Each one is a .md that defines a focused specialist you can delegate a specific task to — technical, content, schema, local, backlinks, performance, and more. Click any card to open the agent definition.

🧭 What an agent is / how to use one

One agent is a specialist with its own scope and instructions, which you call on for a focused task—the main Claude delegates the work, the agent returns a report, and the main context stays clean. It’s the foundation for running several tasks in parallel (subagents).

  • Definition: each file .md below describes an agent (role, when to use it, tools).
  • Install/use: use the content as a reference to create/install agents in your workflow, or ask Claude to "run the agent seo-technical on this site".
  • In parallel: combine several (e.g., technical + content + schema) for a complete audit — see the prompt P16 in the Prompt Bank.

18 SEO agents

seo-backlinks

Backlink analyst using free and paid sources; confidence-weighted merge.

seo-cluster

Semantic clustering via SERP overlap; hub-and-spoke architecture.

seo-content

Content reviewer: E-E-A-T, readability, depth, and thin content.

seo-dataforseo

DataForSEO data analyst: live SERP, keywords, backlinks, and on-page data.

seo-drift

Captures baselines and compares snapshots to detect regressions by severity.

seo-ecommerce

E-commerce SEO: product schema, Shopping/Amazon, and pricing gaps.

seo-flow

FLOW framework analyst: applies stage prompts and returns structured output.

seo-geo

AI search (GEO) specialist: AI crawler, llms.txt, and citability.

seo-google

Google API analyst: CWV via CrUX, indexing via GSC, traffic via GA4.

seo-image-gen

Audits OG/social images and plans their generation with prompts (doesn't generate them on its own).

seo-local

Local SEO: GBP, NAP, citations, reviews, local schema, and location pages.

seo-maps

Maps intelligence: rank geo-grid, GBP audit, and NAP verification.

seo-performance

Measures and evaluates Core Web Vitals and loading performance.

seo-schema

Schema expert: detects, validates, and generates Schema.org in JSON-LD.

seo-sitemap

Sitemap architect: validates XML, generates new sitemaps from templates, and enforces gates.

seo-sxo

SXO: reverse-engineers SERPs, detects mismatches, and scores by persona.

seo-technical

Technical specialist: crawling, indexing, security, URLs, mobile, CWV, and JS.

seo-visual

Visual analyst: screenshots, mobile rendering, and above-the-fold analysis (Playwright).
